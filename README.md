## What is obscurebit?

> *It's both closed and open.*

obscurebit is a creative and technical playground — part studio, part lab, part experiment. Since 2013, we've been poking at the edges of what's possible with software, design, and the odd intersection of ideas that don't quite fit anywhere else.

Some things live in the dark. Some things escape into the wild. The ones that escape end up on **[obscurebit.com](https://www.obscurebit.com)** as live open experiments you can explore.
